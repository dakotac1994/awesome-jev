# Contributing to Awesome Jev

Jev launched September 15, 2026 — this list moves fast. Contributions welcome: new projects, articles, benchmarks, recipes, and corrections.

## What belongs here

- **Community projects** — real things built on Jev (or its open-source clones), with a link and a one-line description. "Real" means a repo, demo, or writeup — not a tweet saying you'll build something.
- **Articles & explainers** — substantive writeups: overviews, technical deep dives, benchmarks, critical analysis.
- **Recipes** — decision patterns in `docs/recipes.md` with copy-paste-able code.
- **Corrections** — pricing, specs, and claims change; fix them with a source.

## What doesn't

- Affiliate links, paywalled-only content with no substantive free summary, or projects that merely mention Jev without using it.

## How to add an entry

1. Put it in the right README section (alphabetical within subsections where it makes sense).
2. One line: **bold name** (or link) — what it is, plus the one number or fact that makes it interesting.
3. Link to the **primary source** (the project repo, the article itself). If you only have a writeup *about* the project, label it as such: `**name** — description ([via Source](url))`. Never guess a URL — link what you actually have.
4. If it touches pricing, specs, or benchmarks, update the relevant docs page too.

## Pull requests

- CI runs a link check (lychee) on every README/docs change — make sure your links resolve.
- Keep the tone factual. Company claims get attributed ("TypeSafe reports…"); independent checks get labeled as such.

## Reporting an issue

Found a dead link, a wrong spec, or a project that should be listed? Open an issue with the correct info and a source.
